# Tanu ✦ — 3D Portfolio

A cinematic 3D portfolio for Tanishka "Tanu" Singh — badminton player, published author, chess
player, artist, and public speaker — built on a warrior/forge-themed React + Three.js codebase
with a katana-slash opening sequence and a draggable procedural 3D blade.

## Sections
- **Hero** — name, tagline, and the interactive 3D katana
- **Michi (The Path)** — her journey on court, in print, and off the board
- **Shugyō (Training)** — badminton and authorship, as full detail cards
- **Buki (Arsenal)** — on-court, creative, and mind-games skills
- **Senji (Campaigns)** — a rotating carousel of her highlights
- **Renraku (Contact)** — email

## Run it locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```

The visual system (dark palette, red/gold accents, glass panels, hover tooltips, the katana
scene, and the slash-reveal intro) is unchanged from the original template — only the content
is Tanu's own.
